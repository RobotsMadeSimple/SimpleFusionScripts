# SimpleFusionScripts

Autodesk Fusion add-ins and scripts from Robots Made Simple.

| Add-in | What it does |
|---|---|
| [BuildBook](BuildBook/) | Build-manual exploded views: sections and steps, explode moves with trail lines, per-step camera views and PNG export. |

## Installing an add-in

1. Clone this repository.
2. In Fusion, open **Utilities → Scripts and Add-Ins**, go to the **Add-Ins** tab, click **+** and choose the add-in's folder (e.g. `BuildBook/`).
3. Select it and click **Run** (tick **Run on Startup** to load it every time).

Each add-in's folder has its own README.
